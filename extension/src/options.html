Custom Hover Translate — 设置

所有设置保存在 chrome.storage.local。后端优先,.env 默认值即可工作;这里只是临时覆盖。

后端连接

默认 http://127.0.0.1:12308(与 backend/.env 中 PORT 一致)。

Provider / Model / API Key(可选覆盖)

保存时同步调后端 /select-provider。Key 存 chrome.storage.local(仅本机可见)。

自动翻译(全局)

点 popup 里的 「整页双语对照」 或 「整页仅译文」 按钮,即可启用全局跟踪翻译(新页面、FAQ 展开、SPA 路由变化自动跟进)。再点 「切换」 按钮可一键在双语/仅译文间切换。无需在此页面配置。
